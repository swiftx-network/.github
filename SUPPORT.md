## Community Support

For questions, discussion, and real-time help:

### Discord — fastest response
<!--[discord.gg/swiftx](https://discord.gg/swiftx)-->

Use the right channel:
| Channel | For |
|---|---|
| `#general` | General discussion |
| `#dev-support` | Technical questions, integration help |
| `#contracts` | On-chain program questions |
| `#sdk` | TypeScript SDK questions |
| `#announcements` | Protocol updates (read-only) |

### GitHub Discussions - longer-form questions
[github.com/swiftx-network/contracts/discussions](https://github.com/swiftx-network/contracts/discussions)

Best for questions that need a detailed answer, architecture discussions, or
protocol-level proposals that are not yet ready to be issues.

### Twitter
<!--[@swiftxnetwork](https://twitter.com/swiftxnetwork)-->

For announcements and general questions. Not monitored for technical support.

---

## Bug Reports & Feature Requests

If you have found a reproducible bug or want to request a feature, open a
GitHub Issue in the relevant repository:

| Repository | Issues URL |
|---|---|
| `contracts` | https://github.com/swiftx-network/contracts/issues |
| `sdk` | <!--https://github.com/swiftx-network/sdk/issues--> |
| `app` | <!--https://github.com/swiftx-network/app/issues--> |
| `docs` | <!--https://github.com/swiftx-network/docs/issues--> |

Please use the issue templates — they help us help you faster.

---

## Security Vulnerabilities

**Do not open public issues for security vulnerabilities.**

See [SECURITY.md](SECURITY.md) for our responsible disclosure process and
bug bounty programme.
